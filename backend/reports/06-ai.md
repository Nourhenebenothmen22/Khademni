## 1. AI Architecture Overview

The Intelligent Teacher Recruitment Platform employs an **In-Process, Multi-Tiered Hybrid Matching Engine** designed to parse teacher CVs, generate 384-dimensional dense semantic vector embeddings, and rank candidate suitability against job posts with zero external API dependencies:

```
[ Application CV (PDF/DOCX/PNG/JPEG) ]
                   │
                   ▼
     [ Binary Magic-Byte Detection & Text Extraction ]
     └─ Validates file-type in memory; extracts text via pdf-parse
                   │
                   ▼
     [ Local ONNX Transformer: Xenova/all-MiniLM-L6-v2 ]
     └─ Generates 384-dimensional dense vector embeddings
                   │
                   ▼
     ┌─────────────┴───────────────────────────────┐
     ▼                                             ▼
[ PostgreSQL pgvector ]                  [ PostgreSQL tsvector ]
(Dense Cosine Distance <=>)              (Sparse Lexical / BM25)
     │                                             │
     └──────────────────────┬──────────────────────┘
                            ▼
              [ Reciprocal Rank Fusion (RRF) ]
              └─ 1 / (60 + dense_rank) + 1 / (60 + sparse_rank)
                            ▼
              [ Rule-Based Qualification Evaluator ]
              ├─ Degree Hierarchy Regex (PhD > Master > Bachelor)
              ├─ Non-overlapping Experience Date Merging
              └─ Weighted Keyword Extractor (REQUIRED, OPTIONAL, BONUS)
                            ▼
              [ Cross-Attention Contextual Reranker ]
              └─ Token overlap & contextual scoring in parallel
                            ▼
              [ Final Synthesized Candidate Score (0-100%) ]
```

## 2. Component Breakdown

### 1. Document Ingestion & Vector Extraction (`document-parser.service.ts`)
- **Text Extraction**: Uses `pdf-parse` for PDF resumes and regex sanitizers for Word/text documents.
- **In-Memory Magic-Byte Validation**: Integrated before parsing to reject polyglot files and binary spoofing.
- **Dense Vector Embedding**: Embeds parsed resume text into a 384-dimensional vector using `@xenova/transformers` (`Xenova/all-MiniLM-L6-v2`).
- **Persistence**: Saves embedding to `document_parse_results.embedding` (`vector(384)`) and upserts into `candidate_hybrid_indexes` with `organization_id`, `job_post_id`, dense vector, and `to_tsvector('simple', content)`.

### 2. Hybrid RRF Vector Search (`hybrid-search.service.ts`)
- **Tenant Isolation**: Injects `WHERE organization_id = $organizationId` across all SQL Common Table Expressions (CTEs), eliminating cross-tenant vector leakage.
- **Dense vs Sparse RRF Fusion**:
  $$\text{RRF Score} = \frac{1}{60 + r_{\text{dense}}} + \frac{1}{60 + r_{\text{sparse}}}$$
- **Cross-Attention Reranking**: Executes `rerankCandidatesWithCrossEncoder` in parallel (`Promise.all`) to evaluate contextual token overlap between candidate profile text and job context.

### 3. Rule-Based Qualification Evaluator (`matching.service.ts`)
- `DEGREE`: Evaluates academic hierarchy using word-boundary regex patterns (`\b(master|msc|ma|magister)\b`), preventing substring false positives (e.g. French word "ma").
- `EXPERIENCE`: Parses employment start/end date intervals and computes non-overlapping union intervals, preventing duplicate counting of concurrent roles.
- `CERTIFICATION`: Checks teaching credentials (e.g. QTS, CELTA, TEFL, State License).
- `KEYWORD`: Applies category-specific weight multipliers (`REQUIRED` 3.0x, `OPTIONAL` 1.0x, `BONUS` 0.5x).

## 3. AI Model Governance & Benchmark Evaluations

The `ai-models` module provides governance tools for AI algorithms:
- **`AIMatchingModel`**: Registers model variants, versions, and hyperparameters.
- **`AIMatchingModelEvaluation`**: Logs evaluation runs against labeled benchmark candidate datasets.
- **`AIMatchingMetric`**: Tracks quantitative metrics: `ACCURACY`, `PRECISION`, `RECALL`, `F1_SCORE`, `PRECISION_AT_1`, `PRECISION_AT_5`, `NDCG_AT_5`, `MAP`, `MRR`.
- **Authorization**: Model registration and metric creation routes are strictly restricted to Platform Super Admins (`isSuperAdmin: true`).
